# Автодом Sprinter 4×4

Сайт-презентация концепта автодома на базе полноприводного Sprinter.

## Запуск

Откройте `index.html` двойным кликом — этого достаточно, сборки нет.

Если браузер капризничает с локальными файлами, поднимите статику:

```
python3 -m http.server 8000
```

и откройте http://localhost:8000

## Что внутри

```
index.html              весь сайт: разметка, стили, логика
assets/img/             фотографии интерьера и экстерьера
assets/fonts/           TT Travels Next (акцентный шрифт)
CLAUDE.md               как устроен файл и по каким правилам его править
```

Шрифт Onest подключён с Google Fonts, то есть при открытии нужен интернет.
Без него текст отрисуется системным шрифтом, вёрстка не поедет.

## Разделы

1. Обзор — машина целиком, характеристики, интерактивная планировка
2. Интерьер — материалы, кухня, спальня день/ночь, санузел
3. Инженерия — автономность, схемы энергии и воды, климат
4. Машина и конструкция — хранение, четыре фургона-кандидата, послойный разрез
5. Система — три уровня, сценарии жизни, конструктор компоновки
6. Производство — путь модуля от файла до фургона, разрез стыка
7. Задачи и вопросы — что проект обязан решить и где заметки спорят с концептом

## Хостинг

Папка статическая — заливается как есть на любой хостинг: GitHub Pages,
Netlify, Vercel, обычный nginx. Точка входа `index.html`.
